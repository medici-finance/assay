v1.0.0: briefs migrated brief-v1 -> brief-v2 (generated board). Add `statusgen reconcile --backfill` to your board workflow (see docs/release-notes/v1.0.0.md).
v1.0.7: the plugin manifest version now equals the umbrella tag (#789) — before this, every tag carried plugin 1.0.0 and `claude plugin update assay@assay` was a no-op, so a cache holding 1.0.0 never received newer content. One-time recovery if `claude plugin list` still shows assay at 1.0.0: `claude plugin uninstall assay@assay` then `claude plugin install assay@assay` (a fresh install rewrites the cache; `update` does not at an unchanged version). From v1.0.7 on, `claude plugin update assay@assay` moves the cache with each release.
