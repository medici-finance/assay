# Investigations

One file per brittle investigation lands here, written by the strong-tier session from [`docs/brittle-investigation-template.md`](../brittle-investigation-template.md); on `redesign`, its refactor oracle lands beside it; nothing else does.
Filename: `<yyyy-mm-dd>-<module-slug>.md`, the date it was written and the module path with `/` turned into `-` (a superseding revision is a new dated file; the old one is never edited).
An oracle is `<yyyy-mm-dd>-<module-slug>-oracle.md`, from [`docs/refactor-oracle-template.md`](../refactor-oracle-template.md); the design brief's `oracle:` line points at it.
A file's `recommendation:` is what the `investigation` column of the mark table in [`docs/contracts.md` §Brittle marks](../contracts.md#brittle-marks) links to.
