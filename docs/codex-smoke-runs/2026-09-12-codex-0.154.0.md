## Run conditions and deviations (stated up front)

1. **Isolated `CODEX_HOME`.** The steps ran with `CODEX_HOME` pointed at a throwaway
   directory holding only a two-line `config.toml` (`model`, `model_reasoning_effort`)
   and a copy of the existing credentials. Rationale: the workstation's own
   `~/.codex/config.toml` already carried a `[marketplaces.assay]` entry
   (`source_type = "local"`, `source = <a local path from an earlier 2026-09-07
   attempt>`) together with `[plugins."assay@assay"] enabled = false`. Step 1's
   precondition is "no prior Assay install", so a stale local marketplace pointing at a
   different tree would have contaminated the install arm; isolating also avoided
   mutating the driver's own config. No secret material from that file is reproduced
   here. Nothing else in the driver's config was read into the run.
2. **Arms A and B were exercised in sequence, not together.** Arm A was installed,
   proven, then fully removed (`codex plugin remove` + `codex plugin marketplace
   remove`) before arm B was placed, so arm B is proven standing alone.
3. **Steps 6b, 7 and the Step 5 controls ran with the workstation's desk-tool shims
   removed from `PATH`** and with `GH_CONFIG_DIR`, `GIT_CONFIG_GLOBAL` and
   `GIT_CONFIG_SYSTEM` neutralised, so no forge credential of any kind was reachable
   from the session. A bare adopter has no desk-tool install either, so this is also
   the more faithful posture.
4. **Step 6b was aborted at the observable**, per the protocol's intent: the prompt
   told the session to stop once its isolated worktree existed. Nothing was
   implemented, committed or pushed.
5. Every step ran under `codex exec` with `--json` (event transcript) and
   `-o` (final message). The excerpts below are cut from those files.
