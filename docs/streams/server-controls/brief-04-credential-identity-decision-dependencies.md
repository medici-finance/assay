facts:
- Three open human decisions own the credential/identity ground a non-author-controllable runner
  stands on: **#900** (runtime credential contract), **#903** (in-process git transport/auth),
  **#942** (a mintable write-issues identity role). All three are open, needs-decision.

  and token for the cross-operator check) cannot be finalised before those rulings land. This note
  records that edge so the wait is visible on the board, not discovered at implementation.
- This brief authors NO decision and re-opens none. It cites the three by number and subject only.
