# streams/

Each initiative is a **stream** — a directory under `docs/streams/<stream>/` with a
README (frontmatter + a brief table) and self-contained `brief-NN-*.md` files.
Append-only registers live alongside: `FINDINGS.md` (knowledge that invalidates a
brief) and `INTAKE.md` (raw ideas).

`statusgen` reads these to generate the `STATUS.md` board and to lint the set in CI.

## Generated regions in a stream README

Two regions of a stream README are generated by `statusgen` (`--regen` rewrites
them, `--lint` reports a hand edit as a problem); everything outside the markers is
authored prose and is never touched.

- **Briefs table** (`statusgen:briefs:begin` / `end`): the brief rows, owned by
  `statusgen/readmetable.go`.
- **Milestones** (`<!-- statusgen:milestones:begin -->` / `<!-- statusgen:milestones:end -->`):
  a separate region, present only in a stream that opted into milestones
  (`reader-requirements` naming `milestone-v1`) and that placed the markers. It
  renders the plan-time facts of each milestone record: supported scope,
  prerequisites, evidence links, the generated reverse membership (work item to
  milestones) and the coverage line with its unknowns. It carries **no** work
  remaining, acceptance, availability or hold column: those change without a
  commit, so they are read live from the `stream-view/v2` projection or
  `deskboard milestones`, never maintained by hand. Markers in a stream that did not
  opt in are a lint problem and a regen error; no region is ever invented for a
  fixture or outline stream. A README without the markers is unchanged.
