# Brief 11 — DORA/insights hybrid: Apache DevLake + our methodology metrics

> ## Settled direction (Ian, 2026-08-18): DevLake FEEDS INTO the retained internal roadmap pages
>
> An earlier framing split the roadmap rollups OUT to DevLake and tombstoned the internal
> roadmap pages. **Ian inverted that (2026-08-18):** the internal roadmap pages are PREFERRED —
> they gather other methodology metrics alongside DORA, and **DevLake feeds/merges INTO those
> html pages, not the reverse.** Consequently:
>
> - **`roadmap.go` + `roadmap_streampage.go` (and their tests) are RETAINED**, not deleted. The
>   per-stream roadmap-page subsystem (`--roadmap`, `renderAllStreamPages`, the per-stream DORA
>   tile) stays. The regenerated roadmap page is NOT tombstoned — it is still regenerated by
>   `--roadmap`.
> - The **grouped-DORA computation the roadmap pages consume** (`computeDoraGrouped` + its
>   `DoraGroup`/`DoraGroupedReport` types and brief-history helpers) is RETAINED — it is the
>   in-Go source the roadmap DORA tiles read today and that DevLake will later feed. It is
>   rehomed out of `dora.go` into a retained file (`roadmapdora.go`) so `dora.go`'s **standalone
>   commodity `--dora` CLI surface** can still be removed. `medianDur` + `p90Duration` move with
>   that core (issues.go needs them).
> - **Still cleanly removed:** `codeefficiency.go`, `trend.go` (its awaiting-verification backlog
>   curve already rehomed), and `dora.go`'s standalone commodity surface
>   (`--dora`/`--dora-series`/`--dora-grouped`).
> - **Newer modes retained** (added independently of this split): `--autonomy`, `--issues`, `--cynefin`.
>
> Read the Context/Task/Verify below under this direction: wherever older text implies "remove
> roadmap", the settled intent is "retain roadmap, and have DevLake feed into it."

## Context

files:

  after rehoming trend.go's awaiting-verification backlog curve (see facts) — and `dora.go`'s

  (next bullet).
- **retain in `statusgen/`**: `roadmap.go` + `roadmap_streampage.go` (the internal roadmap-page
  subsystem DevLake feeds INTO); the grouped-DORA core the roadmap consumes (`computeDoraGrouped` +

  from `dora.go` into `roadmapdora.go`; the newer `--autonomy`/`--issues`/`--cynefin` modes;
  `bottleneck.go` (391 — factory-floor WIP×dwell), `emit.go` debtCounts (verification-debt),

  current metric → DevLake | ours | dropped (the retained curve is rehomed to
  `statusgen/methmetrics.go` (planned) as the `--verif-backlog` mode)

facts:
- **Operator direction (Ian, 2026-08-12) is the charter: hybrid, NOT deletion.** DevLake serves the
  commodity half; the methodology half stays ours, first-class.
- **The split line, per metric:** OUT to DevLake — lead time, deploy frequency, PR throughput,
  change failure rate, velocity/trend curves, roadmap rollups, code-efficiency ratios. RETAINED as
  ours — factory-floor WIP×dwell bottleneck, verification-debt (awaiting-verification counts),
  ‡-derived coverage counts, issue-loop net-delta, gate-queue age. DevLake cannot express the
  retained set: they are derived from brief/Evidence semantics DevLake has no model of.
- **The trend.go trap (found at freshness check):** `trend.go` is on the OUT list but carries the
  awaiting-verification backlog curve (trend.go:12, :245) — a RETAINED metric. Rehome that curve
  into a retained surface (`methmetrics.go`) BEFORE deleting the file; a straight file deletion
  silently drops a methodology metric, the exact anti-hybrid failure.
- **DevLake facts:** Apache-2.0, self-hosted; ingests GitHub via connection + scope config;
  deployment target is the **platform k8s cluster** (operator-named); the GitHub orgs to ingest are
  named in the connection config. GitHub App/PAT provisioning for ingestion and the k8s apply are
  human/platform acts — this brief stages config and runbook, it does not deploy.
- **The consolidated collector is the mapping upstream:** the metric map is drawn against the
  consolidated collector's output set (the prior collector-consolidation work), so every harvest view gets
  exactly one home — DevLake, ours, or dropped — with no metric mapped twice.
- **The board/lint spine is out of bounds** — the review's "protect the lint/board spine" caveat
  survives untouched.
