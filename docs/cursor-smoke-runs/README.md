# Cursor smoke runs

Committed run logs for the scripted live-harness checklist in
[`../cursor-smoke-protocol.md`](../cursor-smoke-protocol.md)
(brief [harness-portability/13](../streams/harness-portability/brief-13-cursor-live-desk-smoke.md)).

- One file per run, named `<date>-<cursor-version>.md`, started from
  [`TEMPLATE.md`](TEMPLATE.md).
- A run log is evidence only when every step carries a transcript excerpt, the surface it
  came from, the model Cursor served (or `model: unrecorded`), and a `Result:` line. A step
  with no excerpt is not evidence.
- The API key and any forge credential never appear in a run log.
