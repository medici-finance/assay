### Changed
- `deskinbox`, `issueboard` and `deskread` now parse their command lines with the shared Cobra and Viper adapter. Help and `--version` read no configuration, start no program and write nothing: `-h`, `--help`, `help <verb>` and `<verb> --help` print generated usage on stdout and exit 0 (for `deskread` this was usage on stderr with exit 5). Every existing call form keeps working, and `--flag=value` now works as well; `--` ends options. An unknown flag is refused with exit 5 as before. The message is now `unknown flag: --x` (`deskinbox` said `unknown option`). A malformed value (`--item`, `--since`, `--sla-days`, `--repo`, `--issue`, `--change`, `--max-parallel`) or an unknown subcommand is refused before the configuration echo, the kill switch or the audit line.
