- Fix `opmetrics` day-files leaving the autonomy ladder's rungs 3 and 4 unmeasured (#5470). The collector now writes a `dispatch` block (loop-initiated, operator-initiated and unattributed subagent dispatches, read from each prompt's recorded origin) and a `token_efficiency` block (subagent tokens, merged PRs, no-op runs and total runs, with a versioned `noop_classifier`). Both are counts only and are added inside `opmetrics/2`, so older day-files still read. A session with subagent transcripts no longer has its main transcript skipped as a duplicate of its own subagent files. Because those subagent files are now read, `operator.transcript_files` counts each of them as well as the main transcript, so that series steps up on the first day-file this producer writes (one session with four subagent runs reads 5, not 1); `sessions_observed` is unchanged.
