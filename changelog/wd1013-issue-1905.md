### Fixed
- `deskwt remove` now clears a registered worktree whose `.git` link is gone (an empty-directory husk, or a directory already deleted) instead of exiting 6 and leaving its branch registered forever. It removes the registration only when the directory is empty, nothing holds it open, the admin HEAD is recoverable, and any lock belongs to the calling session or a session the roster proves gone; a husk with files, an unattributable lock, or git's in-flight lock is still refused.
