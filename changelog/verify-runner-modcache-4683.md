### Fixed
- `statusgen verifyrun --sandbox=container-netns` names the cause when the verify-runner image's baked Go module cache is older than the verified tree's `go.mod` (#4683). The image now records the module roots it baked in `/usr/local/share/verify-runner/go-module-roots.txt`; before any row, verifyrun compares each root's requirements with the cache and prints the gap once, and a row that then stops on a missing module is recorded could-not-run with `image module cache predates go.sum (<module> <want> vs <have>)` instead of an unexplained failure. Rows that do not touch a missing module keep their own verdict.
