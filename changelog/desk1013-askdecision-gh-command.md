### Added
- `ask-decision` Reply shape now carries the exact command for the recommended option, ready to paste: a ruling is `GH_TOKEN="$(gh auth token --user <driver-login>)" gh issue comment <N> -R <owner>/<repo> --body "<ruling text>"`, and an act the driver performs (such as a merge) is the matching `gh` command behind the same prefix. Setting `GH_TOKEN` explicitly pins the driver's identity, so a ruling cannot post under an exported App token or the wrong active account. When no single command expresses the option, the skill says so instead of inventing one.
- `assay-inbox.sh --walk` / `--html` and `deskinbox walk` / `html` render a `command:` line in Reply shape. It is derived only from a phrase the issue states (a "How to answer" section's first quoted phrase, or a fork-test `default:` that names one of its own `option:` letters), single-quoted for the shell, with the login taken from `DRIVER_LOGIN` when that is set. Otherwise the line reads `command: not derivable — desk to fill`.
