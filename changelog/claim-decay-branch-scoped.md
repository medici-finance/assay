### Fixed
- statusgen claim decay reads pull-request state per live branch (`gh api graphql` over the repository's branches, newest PRs first, one query per 100 branches) instead of `gh pr list --state all --limit 1000`. The old read grew with total PR history and stopped at 1,000 PRs, so a corpse branch whose PR was older than the newest 1,000 was never decayed and held its brief off the board. A branch is now a corpse only when its newest same-repository PR is merged or closed and its tip is still that PR's head, so a reused branch name with a newer open PR, or a branch pushed again after its PR closed, stays a live claim.
