### Fixed
- `deskclaim-ref` no longer takes the next flag as a flag's value. Before, `--repo --branch -` set the repository to `--branch` and then refused with "unknown flag -". `--repo --branch=-` named a repository `--branch=-` and failed with "no published owning root". Both now refuse with `refused: --repo requires a value` and read and write nothing. The parser now matches `tools/dispatch-claim.sh`: an absent or empty value, or one that is itself a `--` flag, is refused, and a bare `-` (the branch placeholder for a branchless claim) is still accepted. Value flags now also take `--flag=value`, so `--branch=-` works the same as `--branch -`.
- `deskdispatch` now prints its NOT LAUNCHED `progress` and `release` commands for the Go claim tool as `cd <root> && deskclaim-ref …`, so they run in the same directory as the dispatch's `acquire`. Before, running the printed command from a checkout that did not declare the repository failed for a work-reference key with "no published owning root".
- `deskclaim-ref progress` advances a claim given by its plain physical key even when the repository publishes no owning root, instead of refusing with "no published owning root". A claim that carries a negotiated subject is still refused by the legacy writer, and `acquire` still requires the owning root.
