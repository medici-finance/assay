### Fixed
- `deskclaim-ref` no longer takes the next flag as a flag's value. Before, `--repo --branch -` set the repository to `--branch` and then refused with "unknown flag -". `--repo --branch=-` named a repository `--branch=-` and failed with "no published owning root". Both now refuse with `refused: --repo requires a value` and read and write nothing. The parser now matches `tools/dispatch-claim.sh`: an absent or empty value, or one that is itself a `--` flag, is refused, and a bare `-` (the branch placeholder for a branchless claim) is still accepted. Value flags now also take `--flag=value`, so `--branch=-` works the same as `--branch -`.
