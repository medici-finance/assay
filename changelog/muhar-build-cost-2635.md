### Added
- `muhar` can build a spec's mutants once per worker instead of once per mutant. A spec that sets `"schemata": true` has its eligible in-function edits compiled together as a mutant schemata (a `-overlay` tree with an environment-selected switch per mutant), so a mutant costs a link and a test run instead of a full compile and vet; on the deskkit spec this cut CPU time by 60% with a byte-identical report. It is opt-in because it assumes the suite never cross-checks the running code against its source on disk or against a child process that drops the environment; a schemata NOT CAUGHT is always re-run the classic way, and specs without the field run exactly as before. `internal/deskkit/mutations.json` opts in.
