### Changed
- `qualgen` now parses its command line with Cobra and resolves each verb's settings through a fresh Viper instance. Help and `--version` read no environment, file or repository: `-h`, `--help`, `-help`, `help <verb>` and `<verb> --help` print generated usage on stdout and exit 0 (a verb's `-h` used to print usage on stderr and exit 2). Every existing call form keeps working, including the Go-flag spellings `-out x` and `-out=x`, repeated flags (the last wins) and `--`. Unknown flags, malformed values and stray arguments on `mine`, `report`, `sweep` and `init` are refused with exit 2 before anything runs; a second `pr` number is refused as well. `check` and `pr` now accept their paths or PR number anywhere on the line, not only first.
