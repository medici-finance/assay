### Changed
- `statusgen verifyrun --bracket-digest --credit` now credits a version-2 (cross-repository) container span instead of answering `credit=not-credited` for every one. The span must pass both repository checks. The tracking repository, where the attestation record lives, must be the brief's own. The source repository (`source-repo=`) must be in the configured repository set, either an explicit `ASSAY_ALLOWED_REPOS` entry or an `owner/*` pattern. A span whose source repository is outside that set is `credit=not-credited`. The roster alone decides this, so no forge read is made. The record is admitted under the same version-2 rules the desk tools' attestation reader applies. Its rendered line, including `source-repo=` and `tracking-source=`, must equal the span's line.
