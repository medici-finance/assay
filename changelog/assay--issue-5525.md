### Fixed
- `deskdispatch`'s human-decision gate now ensures its decision issue in the repo that tracks the brief, not the repo its deliverable lands in. A `gate: human` brief declared `homed-in:` (or dispatched with `--cross-repo`) used to run the decision helper against the deliverable repo, where its dedupe could not see the existing decision issue, so it filed a second one or failed closed. When the tracking repo cannot be resolved, the dispatch now refuses before the claim instead of falling back to the deliverable repo, and `--dry-run` names the repo the gate would use (#5525).
