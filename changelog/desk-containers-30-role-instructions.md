### Added
- `cellctl` binds a Codex role's `instructions` file as `-c developer_instructions=<text>` on the standing and the cadence launch. A Codex role that declares a key with no Codex binding is refused with that key named, instead of every non-empty entry being refused.
- A role context can declare `dispatch_instructions`, a map from dispatch kit to file. `cellctl` digests each file at launch and passes it to the window in `ASSAY_DISPATCH_INSTRUCTIONS`; `deskdispatch` re-checks the file's location and digest, then quotes it in the prompt of every dispatch of that kit after the class kit. The dispatch record gains `dispatch_instructions_sha256`. `cellctl check` prints one row per kit and refuses a missing file, an unknown kit, a path the value cannot carry and a file a role session can write.
