### Fixed
- The board pushes (STATUS.md regen, QUALITY.md regen, gate:model auto-flip, and the GitLab regen job `statusgen init --forge gitlab` scaffolds) no longer read an expired credential as "push rejected: main moved". Each push failure is classified as expired, revoked, scope, auth, nonff or other by `statusgen/pushcred.sh`. Only a non-fast-forward rejection retries or says that main moved. Every credential class fails once with its own message and spends no retry (#2910).
- The credential is checked before the board commit is written and before every retry: a dry-run push, plus GitLab token self-introspection on the GitLab template. The GitLab regen job's push token now reaches git through an inline credential helper instead of the remote URL. Git output is masked, including GitHub fine-grained and dotted GitLab token shapes, and the push logs are created owner-only (#2910).
