### Added
- `deskdispatch --attest-worker` gives a fresh worker dispatch a stamp target before its PR exists. Before the prompt is emitted, the verb creates a dispatcher-authored `[worker-attestation]` record, stamps it with the authoring model/tier, closes it and reads it back. The record binds the run, item, kit, branch, base commit, source digest and model/tier. Any failure emits no prompt and releases the claim (exit 6). The coordinator's post-open `--stamp-only` call (optionally with `--attestation <N>`) reads the record named by the PR's `Worker-Attestation:` line and refuses a change whose branch, kit or model/tier disagrees. It never infers the stamp from the record. The flag is opt-in, and intake listings exclude these records the same way they exclude verifier records.
