### Added
- New pure Go module `deskcore` (no third-party dependencies) with four effect-free packages:
  - `domain`: shared identifiers, revisions, facts, requests, the six result kinds and receipts.
  - `facts`: a reader for the `desk-facts-v1` fact-bundle contract, published as a JSON Schema at `deskcore/schemas/desk-facts-v1.json`. The reader refuses unknown schemas, and its queries tell present, known-negative, stale and could-not-check apart.
  - `policy`: a skeleton for approved-policy data.
  - `config`: a resolver for the desk's tunable knobs:
    - precedence is environment `ASSAY_DESK_<KNOB>`, then the config file, then the compiled default;
    - every value records where it came from;
    - out-of-bounds values are refused, naming the knob, the value and the layer;
    - budgets and rates default to off and are counted per role.
- `deskcore/archtest` is a test-time architecture check:
  - It fails when a pure package reaches a process, network or effectful package, or any third-party package, through any import chain.
  - It fails when code outside `config` reads the environment or hard-codes a knob's value.
