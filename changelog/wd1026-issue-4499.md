### Added
- `statusgen verifyrun --acceptance-record` accepts a protected record: a file holding only the `Verification-Table:` line. It closes a protected table whose delivery added supplemental rows but changed no original row, with no acceptance transition and no `--acceptance-forge`. Original rows must equal their delivered definitions and run as delivered; supplemental rows, derived from git at the recorded coordinates, are witnessed `author-added` with no acceptance credit. Original-row changes still need the transition route and its approval.
