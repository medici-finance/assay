### Changed
- The Compose desk services, `desk-run.sh` and the documented `docker run` recipes now set `GODEBUG=multipathtcp=0` themselves, so an older image tag or an operator env-file cannot leave Go MPTCP listeners open (CVE-2026-98432 stopgap; a patched node kernel remains the real fix).
- Tests now hold that setting on every Compose service and sweep every kustomize patch a kustomization lists, file or inline, strategic-merge or JSON6902: they refuse a strategic-merge directive, a null, a non-literal `GODEBUG` entry, and any JSON6902 operation that could remove or replace a pod spec or env entry, and the `GODEBUG` matcher reads the list exactly as the Go runtime does (no whitespace trimming).
