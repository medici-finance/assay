### Changed
- The Compose desk services, `desk-run.sh` and the documented `docker run` recipes now set `GODEBUG=multipathtcp=0` themselves, so an older image tag or an operator env-file cannot leave Go MPTCP listeners open (CVE-2026-98432 stopgap; a patched node kernel remains the real fix).
- Tests now hold that setting on every Compose service and sweep every kustomize patch a kustomization lists, file or inline, strategic-merge or JSON6902: they refuse a strategic-merge directive, a null, a non-literal `GODEBUG` entry, a container or initContainer entry that carries no `GODEBUG` entry (a strategic-merge patch cannot add one unseen), and any JSON6902 operation that could remove or replace a pod spec or env entry, and the `GODEBUG` matcher reads the list exactly as the Go runtime does (no whitespace trimming). The compatibility patch now names the setting on its containers so it passes that rule; the rendered result is the same set of variables.
- Not covered by these tests, and declared so: kustomize `transformers`, `generators` and `replacements`, a patch that wraps a container's `command` or `args`, and Compose files reached through `include:` or named `*.compose.yaml`. The rendered check that sees some of these needs a kustomize binary that the ordinary CI job does not install.
