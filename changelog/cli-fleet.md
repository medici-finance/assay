### Changed
- `deskfleet` now parses its `provision` and `labels` verbs with Cobra through the desk CLI adapter. Help (`--help`, `-h`, `-help`, `help <verb>`) prints to stdout and exits 0 before any environment, file or network read; `deskfleet provision -h` and `deskfleet labels -h` used to exit 2. Every flag keeps its spelling, default and single-dash form, `GITLAB_API_BASE` stays environment-only, and the domain refusals and exit codes 1, 2 and 5 are unchanged. Parse-error wording now follows Cobra (`unknown flag: --x`, `unknown command "x"`), and both verbs accept the shared `--perf-*` attribution flags.
