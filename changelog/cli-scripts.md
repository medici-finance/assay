### Changed
- The changelog and release check scripts now run on one Go command, `deskchangelog` (`tools/desk/cmd/deskchangelog`), with the verbs `aggregate`, `check`, `credit-identity`, `check-spec-header` and `lint-decision-defaults`. `tools/changelog/aggregate.py`, `tools/changelog/check.sh`, `tools/changelog/credit-identity.sh`, `tools/release/check-spec-header-version.sh` and `tools/lint-human-decision-defaults.sh` remain as thin adapters with their call forms, output and exit codes unchanged. Their existing offline suites pass unchanged against the adapters. An adapter runs `deskchangelog` from `PATH`, otherwise builds it from `tools/desk`, and exits 127 when neither is available.
