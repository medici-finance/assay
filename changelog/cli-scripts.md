### Changed
- The changelog and release check scripts now run on one Go command, `deskchangelog` (`tools/desk/cmd/deskchangelog`), with the verbs `unreleased-bullets`, `highlights`, `roll`, `credits`, `check`, `credit-identity`, `check-spec-header` and `lint-decision-defaults`. `tools/changelog/aggregate.py`, `tools/changelog/check.sh`, `tools/changelog/credit-identity.sh`, `tools/release/check-spec-header-version.sh` and `tools/lint-human-decision-defaults.sh` remain as thin adapters. Their call forms keep their output and exit codes, with three differences: an adapter exits 127 when Go is missing or the build fails, a positional argument to `aggregate.py` that starts with a dash needs `--` before it, and `aggregate.py --help` prints help and exits 0. Their existing offline suites pass unchanged against the adapters. In a checkout that carries `tools/desk/cmd/deskchangelog`, an adapter builds the command from that source and never uses a `deskchangelog` on `PATH`; only a tree without the source runs the one on `PATH`.
