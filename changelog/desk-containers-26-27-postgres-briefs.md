### Added
- desk-containers/26 brief: a local PostgreSQL server in Docker for a host running several cells. It covers a pinned image, a persistent volume, a health check, one database and restricted role per cell, credentials supplied at runtime, per-cell dump backups with a stated recovery point and a restore drill, and the `CELL_DB_DSN` / `CELL_DB_PASSFILE` `cell.env` keys a cell reads its database from. Restores load data as a one-shot non-superuser role that a fixed-order teardown removes even when cell code tries to keep it, role passwords reach the server only as SCRAM verifiers, and the isolation it claims is the database layer's: it states that host cells on one OS user can reach the superuser, and what a remedy must withhold. `gate: human` (credential custody). Authoring only; nothing is implemented.
- desk-containers/27 brief: PostgreSQL on Kubernetes with CloudNativePG, as an opt-in Kustomize component beside brief 06's base. It covers a `Cluster`, a `Database` and `DatabaseRole` per cell, Secrets created out of band, object-store backups with WAL archiving, and the explicit local-to-CNPG migration procedure. RBAC keeps `pods/exec`, `pods/attach`, `pods/ephemeralcontainers` and Secret reads to the operator; the migration's data load runs under a port-forward-only identity. `gate: human` (credential custody). Authoring only; nothing is implemented.
