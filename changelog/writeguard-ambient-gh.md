### Added
- `writeguard` refuses a Bash call that runs `gh auth token` (or asks `gh auth status` to print the token) while `DESK_LOOP` or `DESK_SESSION` is set in the hook's environment, naming `desktoken <role>` as the only sanctioned credential path. It judges the executed forms listed in `docs/write-policy.md` (wrappers, shell scripts, pipes and heredocs into a shell, quoting and escapes) in work linear in the command's length, and lists the forms it does not judge. Outside a desk session the hook stays silent, other `gh` use is untouched, and malformed hook input still fails open.
