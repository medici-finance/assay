### Changed
- The desk tools' forge-client source guard now reports more ways of dropping an `io.ReadAll` error, not only `x, _ := io.ReadAll(...)`. It also catches a `var x, _ = ...` declaration, a call whose whole result is ignored, an error variable that is never read afterwards (no later reference, only `_ = err`, or overwritten before any read), `ioutil.ReadAll`, and a same-package function that directly returns `io.ReadAll(...)`. It is still a syntactic scan, with the shared `ReadForgeBody` helper as the control. The `deskevidence` audit-lock notes in the desk-tools README now say that the holder's in-process forge requests are bounded at 30 seconds, and that the `statusgen --decision-gate` child process is the one part of the write window that has no bound.
