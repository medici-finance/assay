- Add `statusgen rowread comments --issue owner/name#N [--issue ...] [--body-contains TEXT]`, a read-only verb a Verify row uses to read issue comments without holding a forge credential (#4700). Each read goes through `deskread`, which mints the role's App token inside its own process. The verb takes only the `comments` kind and refuses anything else (a write verb, another read kind, an unknown flag, a malformed target) before a reader starts. An issue it could not read exits 6 (could-not-check), never an empty answer. It prints one JSON line per matching comment (issue, author, time) and never the comment body. The forge-token scrub on an admitted row's environment is unchanged.
