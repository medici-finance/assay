### Added
- **Runtime adapter contract** (`docs/runtime-adapters.md`). It is a vendor-neutral contract for the stateful resources an agent run needs: database branches, snapshots, eval corpora, object-storage prefixes and disposable app backends. It defines seven adapter verbs and a six-state lifecycle. It also defines the mandatory record fields: owning run, TTL, quota, data classification, credential custody, cleanup owner, cost and recovery semantics. An agent may only request a bounded, ephemeral resource through the control plane. Claiming one past its TTL takes a human or organization principal, and any claim or release rotates or revokes the agent's credential.
- **`statusgen runtime-resource --lint --adapters FILE`** validates runtime-resource records against the new `schemas/runtime-resource-v1.json` and an adapter registry. It enforces reconcile-before-retry: an effect whose acknowledgment was lost must be resolved by a reconcile receipt before the run does anything else, and success is never inferred from absence. It reports three states and runs offline against a local mock adapter, with one fixture per failure class. It reads the receipts in order, so the latest authoritative observation decides the state, and it treats any bound it cannot evaluate as a violation rather than as a bound that holds: an over-long duration, a timestamp anywhere in the record with no real date, or a receipt dated outside its effect's window. An effect list whose request times run backwards fails, because every ordered rule reads that list. Ownership is scoped to one lifetime of the resource: once a resource is observed absent and then present again, a claim from before does not back its ownership block or protect it from an agent's release. The adapter registry refuses unknown keys, so a misspelt `max-ttl` cannot silently remove a ceiling. A directory scan reads `.yaml` and `.yml` files in every subdirectory, and a file with a second YAML document is could-not-check. The eleven rule tags appear as fatal in the generated enforcement-status block of the author-brief guidance.
- `docs/evidence-bundle.md` names the **runtime receipt** as an evidence kind.
