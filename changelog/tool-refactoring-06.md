### Changed
- `cellctl` up, reconcile, down and settle now take their pid-reuse, owner-generation, settle and plan-stale judgments from one pure lifecycle model in `internal/cellcadence` instead of each carrying its own copy; the process, lease and checkpoint reads and writes stay in the adapters. `Lease.RecordStopped` now takes the owner generation (pid, start time, checkpoint sequence and start) and refuses a checkpoint of another generation or an unnamed one. A class guard parses the production source and rejects a second start-time judgment or checkpoint writer. No verb, flag, schema or exit code changes (tool-refactoring/06; implemented, decision still open).
