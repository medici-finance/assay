### Added

- **Stream view contract v1** (`statusgen/streamview`, `docs/stream-view-contract.md`): an importable, versioned wire type for one stream's state — repository-qualified identity (`owner/name` + slug, cell context kept outside the key, renames start a new identity), per-section provenance with explicit availability (`available`, `partial`, `could-not-check`, `not-assessed`; missing never reads as a value), a fixed trailing 24-hour changes window, version negotiation, a strict `Decode` consumer, and `CheckBindings` to dereference recorded revisions and evidence against their owning repository.
- **Optional authored `mission:` block** in stream README frontmatter (outcome, success criteria with evidence references, commitments, exclusions). Legacy streams need no migration; an invalid block is a statusgen lint problem with explicit diagnostics and is never replaced by README prose.
- **Offline acceptance runner** `tests/stream-brief/32.sh` (legacy, identity, negative, flow, dereference, mutation) with fixtures under `statusgen/testdata/streamview`.
