### Fixed
- `deskpreflight`'s junk/oversize check no longer fails every pull request over the repository's own retained quality baselines (`docs/quality/metrics.jsonl`, `tools/go-analysis/baseline.json`). A compiled, exact-path allowlist exempts a listed file from the 5 MiB threshold only while it is byte-identical to its copy at the merge-base with `refs/remotes/origin/main` (committed, staged and working tree) and within a pinned per-file size bound. An unlisted oversize file, an addition under a listed name, a changed or grown baseline and a junk name are still rejected; an unreadable baseline or an unresolvable base is could-not-check (#2813).
