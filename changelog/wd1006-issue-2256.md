### Fixed
- `containers/scripts/layer-secret-scan.sh` now extracts every image layer into its own directory instead of one merged filesystem, so a key written by an earlier layer is detected even when a later layer overwrites that path, replaces it with a directory, or deletes it. Before this, whether such an image passed depended on which layer blob happened to be extracted last. The mutation test adds overwrite, sandwiched-overwrite, and directory-replacement fixtures, and a committed mutation script shows that a merged-view scanner fails each of them.
