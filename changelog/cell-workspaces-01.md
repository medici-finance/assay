### Added
- A shared workspace contract: the new standard-library-only `workspace` Go module (`github.com/medici-finance/assay/workspace`), specified by `spec/cell-workspaces-v1.md` and `schemas/cell-workspace-v1.json`, defines workspace identity (cell, repository and collision-resistant repository key, kind, owner scope, attempt, request, allocation), strict decoding with a canonical payload digest (an exactly specified encoding that leaves `<`, `>`, `&`, non-ASCII characters and U+2028/U+2029 unescaped, pinned by a conformance fixture), identifiers of visible ASCII only and absolute local paths with no network root, `..` segment or control character, request idempotency that refuses a reused key with a changed payload, a generation-checked lifecycle (`allocating`, `ready`, `active`, `retained`, `retiring`, `retired`), and typed `refused` / `conflict` / `unknown` outcomes in which only a successful result carries a workspace. It performs no Git or filesystem effect; the existing `deskwt` owner keeps those until its callers move onto the contract.
- `docs/workspace-callers.md` censuses every production site that creates, removes, prunes, recursively copies or deletes a checkout, or emits a recipe that does, with its source revision, disposition, owner step and retirement condition. `TestWorkspaceCallerCensus` scans the real tree and fails on any unrouted or stale site.
