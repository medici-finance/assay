### Fixed
- `pr-monitor.sh` and `inbound-monitor.sh` now resolve the origin fallback for every github.com URL form (explicit `:443` port, `ssh://` scheme, credentials in the URL, trailing slash), and `assay-inbox.sh` shares the same parser. When the repo set cannot be resolved, both monitors print `MONITOR-DEGRADED: <reason>` on stdout before exiting 1, so the documented watch filter sees the failure instead of a silent stderr-only exit.
