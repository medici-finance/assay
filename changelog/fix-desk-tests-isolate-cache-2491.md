### Fixed
- `tools/desk` tests no longer touch the operator's live cell Go-cache. A test run started from a cell shell inherited `ASSAY_GO_CACHE_POLICY` and took the live cache's exclusive lock through `deskdispatch`'s storage admission and `cellprocess`'s launch custody, so production dispatch on the same machine returned storage-deferred while the tests ran (and the tests failed while production held it). Every package whose code links the managed cache now clears the cell's storage-admission variables in its `TestMain` (new test-support package `internal/cachequiet`), and a static guard fails any new cache-linking package that does not.
