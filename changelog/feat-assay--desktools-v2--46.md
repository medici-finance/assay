### Changed
- `deskpins`, `deskmanifest`, `deskprovenance`, `deskrebaseline` and `deskrelease` now parse their command lines with the shared Cobra adapter. Help and version print to stdout, exit 0, and run before any roster, configuration, credential, network or child-process read. Every documented flag spelling still works, including the single-dash forms (`deskpins -check -root D`, `deskmanifest lint -root D`). `deskrebaseline` now accepts them too (`-row K`). A bare invocation and a parse error keep each tool's old exit code.
- `deskrelease cut` still takes its argv only through the cut parser. An extra operand or unknown flag is refused with exit 5 and audited, and a flag written before `cut` is now refused the same way (it used to exit 2). `cut -h` or `cut --help` on its own now prints help instead of being refused. An unknown verb exits 2 before the kill-switch check runs.
- `deskmanifest lint` and `deskprovenance` now refuse a stray positional word with exit 2. Before, it was ignored.
