### Changed
- `deskpins`, `deskmanifest`, `deskprovenance`, `deskrebaseline` and `deskrelease` now parse their command lines with the shared Cobra adapter. Help and version print to stdout, exit 0, and run before any roster, configuration, credential, network or child-process read. Every documented flag spelling still works, including the Go-flag single-dash forms (`deskmanifest lint -root D`, `deskprovenance -dry-run`). Two tools accept spellings they used to refuse: `deskrebaseline -row K`, and `deskpins -check`, `-root D`, `--check=V` and `--root=D`. A bare invocation and a parse error keep each tool's old exit code. Each root also lists the shared optional `--perf-*` flags, which these tools accept and do not yet record.
- `deskrelease cut` still takes its argv only through the cut parser. An extra operand or unknown flag is refused with exit 5 and audited, and a flag written before `cut` is now refused the same way (it used to exit 2). `cut -h` and `cut --help` are still refused and audited; `deskrelease help cut` prints the verb's help. An unknown verb or root flag still exits 2 only after the startup and the kill-switch check, so a disabled suite still refuses it with 3 and audits it. Help, version and a bare invocation no longer run the roster startup or its activation check.
- `deskmanifest lint` and `deskprovenance` now refuse a stray positional word with exit 2. Before, it was ignored.
