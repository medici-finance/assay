### Changed
- Every desk role skill (`the-desk`, `worker-desk`, `pr-review-desk`, `verify-desk`, `intake-desk`, `pr-shepherd`) now states in its body that every `gh` call, reads included, runs as the role through the guarded recipe in `references/desk-shell.md` §Forge CLI as the role. That recipe takes the role from `$DESK_LOOP` and stops before `gh` unless the `desktoken` mint succeeded and the token file holds a token. A bare `gh` call runs as the host's stored login, which is usually a human's. Before this change the skills reached that rule only through a link inside a long reference pointer.
