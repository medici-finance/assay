### Fixed
- `deskpr create` on GitLab now rides out the post-push race where the merge-request create answers HTTP 400 `{message: {source_branch: [does not exist]}}` for a branch it has just pushed. The bounded retry only recognised GitLab's sentence form ("Source branch ... does not exist"), so this field-keyed form failed on the first response. The retry now matches both forms, backs off 2s, 4s, 8s and 16s (at most 30s over five attempts), and before each retry reads the open merge requests on the source branch. It does not retry if one is open or if that read fails, so it cannot open a duplicate. Every other error is still returned on the first response. When the bound runs out, the failure keeps its could-not-check exit (6) and GitLab's original error text.
