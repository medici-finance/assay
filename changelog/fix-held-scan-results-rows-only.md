### Fixed
- The verify hold scan (read by `statusgen verifyflip`, the verify-gate card, close-verify, the model autoflip and the awaiting board's sign-off act) no longer reads a lower-case "held" or "could-not-check" in an Obligation or Requirement cell of a table that is not a results table as a row disposition. Such a cell names what a row must establish ("Addressed and held exclude ordinary work"). The exception applies only to a table the page is sure to render as one table with the header's own columns: a blank line or heading above it, every line at column 0 and outside fenced code or HTML, a delimiter row with the header's cell count, no backslash in the header, delimiter or row, and no second separator row under it. An upper- or mixed-case marker, a cell that names a row, a misaligned row, a line with a struck span, and every other cell of the table are still read.
