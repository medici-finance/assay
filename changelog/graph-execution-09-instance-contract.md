### Added

- Add the `workflow-instance-v1` contract (`spec/workflow-instance-v1.md`, `schemas/workflow-instance-v1.json`) and `statusgen instance validate --file PATH [--root DIR] [--prior PATH] [--cell CELL] [--json]`. An instance binds one reviewed pattern to one work item in one Cell with pinned acceptance, policy, input and dependency references, and owns the instance, node and attempt identifiers. Its contract is immutable (a change is a superseding instance), attempts and decisions are append-only, and backend assignment moves only by generation. Effects must sit within both the pattern and the actor's capabilities, no credential material is accepted, reporter trust labels never become dispositions, and readers refuse capabilities they do not implement.
- Add the role packet view and handoff for an instance attempt: same identifiers, acceptance revision, coverage with explicit unknowns, omissions and dependency deltas; a handoff bound to a moved dependency or missing mandatory evidence is refused. Export/import is sealed and Cell-bound.
