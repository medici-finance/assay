### Changed
- `opmetrics`, `deskcalibrate`, `deskreconcile` and `muhar` now parse their command lines with the shared Cobra and Viper adapter. Every documented flag spelling still works, including the single-dash forms (`muhar -j 0 -spec F`, `deskcalibrate sample -n 4`). Help and version print to stdout, exit 0, and no longer read the roster or consult the kill switch. A parse error prints `<tool>: <reason>` plus a pointer to `--help`, and keeps each tool's old exit code. `opmetrics -h` after other flags is now help rather than a refusal. `muhar` gains `--version`. A `help` word after any of the four tools' flags is now a refusal, where before it was ignored (or refused with a different message). Flags may now follow positional words.
