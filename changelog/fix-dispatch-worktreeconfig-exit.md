### Fixed
- The desk-tools work-source reader no longer refuses a repository that sets `extensions.worktreeConfig` (`work source repository unreadable: … does not support extension: worktreeconfig`). It now opens the repository through the shared git adapter, which accepts that git-native extension and still refuses any other unsupported one, so an unreadable repository format stays fail-closed. A work-reference claim in such a repository now reaches the same later gates as in a repository without the extension; it can still stop with exit 6 at those gates. A guard test now fails if non-test desk-tools code imports go-git's raw repository opener outside one documented fall-through reader.
- When no repository is given, the work-source reader now derives the origin from its fetch URL only: an `origin` with one `url` plus a `pushurl` is accepted (it was refused as ambiguous before), and two fetch URLs are still refused.
