### Fixed
- `deskdispatch` and `deskclaim-ref` no longer stop with exit 6 (`work source repository unreadable: … does not support extension: worktreeconfig`) when claiming a work reference in a repository that sets `extensions.worktreeConfig`. The work-source reader now opens the repository through the shared git adapter, which accepts that git-native extension and still refuses any other unsupported one, so an unreadable repository format stays fail-closed. A guard test now fails if non-test desk-tools code imports go-git's raw repository opener outside one documented fall-through reader.
