### Fixed
- `verifyflip` provenance: the trivial-merge helper now tests a merge base against the kept side's Evidence and the other side's Evidence independently. It used to skip the kept-side test whenever the other-side test matched, so if both sides' Evidence were equal, a base matching both would have read as "the other side brought nothing". Equal Evidence now always gets the fail-closed answer (the pair does not make the merge trivial). The only current caller never passes equal Evidence, so no flip outcome changes today.
- `verifyflip` tests: the criss-cross refusal test now asserts the refusal names the final merge commit, a new test pins an octopus merge that drops a later FAIL from its third parent, and a stale comment on `TestVflipEveryMergeBase` now gives the right reason the merge is judged.
