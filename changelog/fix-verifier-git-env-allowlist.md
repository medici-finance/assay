### Fixed
- The verifier Git environment now removes every inherited `GIT_*` variable (and `SSH_ASKPASS`) before declaring its own four, instead of a list of eight named ones. `GIT_OBJECT_DIRECTORY`, `GIT_ALTERNATE_OBJECT_DIRECTORIES`, `GIT_INDEX_FILE`, `GIT_NAMESPACE`, `GIT_SSH`, `GIT_EXEC_PATH`, `GIT_SSL_NO_VERIFY` and any other `GIT_*` name no longer reach the verifier runner, a Verify row, or `verifyloop`'s own Git calls. The launch environment and the admission-read environment now share one filter. `verifyloop`'s Evidence landing (the origin and hook-path reads, `add`, `commit`, the race's `pull --rebase`, and the pre-push hook) runs under the same environment. The verifier prompt and `references/desk-shell.md` print a pattern-based `unset` line in place of the fixed list.
