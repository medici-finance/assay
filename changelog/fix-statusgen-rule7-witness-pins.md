### Fixed
- `statusgen verifyflip` and the reconcile fold no longer pass a verifyrun witness row whose hold sits inside fenced code. The witness check reads table rows inside a fence and credits such a row by its first state word, while the held scan skipped the fence, so a fenced row reading `HELD pass exit=0` flipped. On the flip read a fenced witness row is now read for holds; the verify-gate card and close-verify, which run no witness check, are unchanged.
- The held scan's rule 7 (double-quoted output, flip read only) no longer reads a span on a line that carries HTML comment syntax anywhere (`<` or `-->`): a comment opening in another cell or on an earlier line and closing beside the quote hid a quote from the cell's own check. It also no longer reads a span from a quote beside a C0 control or DEL byte, which renders as nothing and turned an inch mark (`5\x01"`) into a quotation mark. Such a hold is refused on every read.
