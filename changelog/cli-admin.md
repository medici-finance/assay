### Changed
- `deskversion`, `deskmigrate`, `deskaudit` and `deskdisable` now parse their command lines with the shared Cobra adapter. Help and version print to stdout, exit 0, and run before any roster, configuration, kill-switch or file read. Every documented form still works, including the Go-flag single-dash spellings (`deskversion -root D`, `deskmigrate -from vX -to vY -dry-run`, `deskdisable C -root D`). A bare invocation, a parse error and a missing `--from`/`--to` still exit 5.
- `deskversion` and `deskmigrate` no longer echo the effective roster config or run the activation check for help or version: `--help` and `-h` used to exit 5 after printing that echo, and now exit 0. A stray positional word is now refused with exit 5. Before, it was ignored and the read ran (`deskversion version` was a marker read).
- `deskaudit` help moved from stderr to stdout. `deskaudit tail --help` and `deskaudit recover --help` print the verb's help; they used to be refused as a bad argument. An unknown verb or a bad `tail N` is still refused with exit 5, now before the kill-switch check, and the message comes in the adapter's form with a pointer to `--help`.
- `deskdisable` accepts flags before the component (`deskdisable --dry-run C`) and answers `C --help`, `C -h`, `C --version` and `-version`. These used to be refused with exit 5.
