### Added
- `desk-shell.md` §Forge CLI as the role: the canonical recipe for a desk's `gh` call. It mints the role App token with `desktoken` from `$DESK_LOOP`, scopes `GH_TOKEN` to the one command, and fails closed with a named diagnostic when the role or its custody is missing. It also separates a desk-authentication failure from a host with no human `gh` login, and personal OAuth is never the repair (#3055). A test holds the recipe's loop-to-role mapping to the desk tools' own table, retired loop names included. The recipe refuses a custody file that holds no token (empty, a bare newline, or only whitespace) before `gh` runs, in both its bash and PowerShell forms: `gh` treats an empty `GH_TOKEN` as unset and would run as the host's stored human login. A second test runs the bash block under bash and zsh against a stub `gh` to hold that.
- `skillslint` ambient-auth check (hard): no skill or reference may tell a desk to read a human's `gh auth token`. The canonical section and the driver's own `gh auth token --user <driver-login>` command are the only exemptions.
