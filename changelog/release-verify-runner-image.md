### Added
- Every umbrella release now builds and pushes `ghcr.io/medici-finance/assay/verify-runner:<tag>`, the Verify-row sandbox image. It is the digest-pinned `golang:1.27.2-bookworm` base plus the release's own checksum-verified linux `statusgen`. The release's `verify-runner` job builds the image after the release publishes, and before pushing it checks that `statusgen` reports the release tag and that the tools a row needs are present. It writes the pinnable `<repo>:<tag>@sha256:<digest>` reference to the run summary. The Dockerfile is `images/verify-runner/Dockerfile`, and `docs/docker.md` describes the image.
