### Fixed
- `upgrade-assay --adopt-umbrella-from-pins` is the supported way past a pin file with per-artifact lines and no `assay` umbrella line, which is what a stock install writes. The flag adopts the release those lines pin only when every eligible line pins one bare `vX.Y.Z` tag and every pinned sha256 matches that release's published `checksums.txt`. It prints that evidence, and the apply writes the missing `assay <target>` line. A digest mismatch refuses as known-inconsistent (exit 5), and any other gap refuses as could-not-determine (exit 6). Without the flag the verb still refuses, and the refusal now names the flag. `deskversion` is unchanged.
- `assay-install.sh pin` now records `assay <tag>` when it writes a pin from a bare `vX.Y.Z` release into a file that has no umbrella line and every per-artifact line pins that tag. An existing umbrella line is never touched, and an unchanged file stays byte-identical.
