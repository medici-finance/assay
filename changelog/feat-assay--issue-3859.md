### Added
- `cellctl cycle <cell> [role...]` takes each role window through drain, sync, check and restart, one role at a time. It drains with `drain`, brings the harness plugin placement to the marketplace pin (claude: the project record; cursor: `deskinstall --release <pin> --check`; codex: could-not-check), reopens the window as `up --role` does, waits for a fresh heartbeat, and prints one report line per role. A drain timeout leaves the role running, names the held claims and exits non-zero unless `--force-after-timeout` is given. A failed placement check leaves the role down. `--all-at-once` drains every role together.
