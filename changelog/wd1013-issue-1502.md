### Fixed
- `statusgen reconcile` no longer treats a pull request that only authored a brief as proof the brief is implemented. A merged PR that adds a brief's file and touches nothing but stream board READMEs, brief files and changelog fragments is skipped by the `Brief:`-trailer fold (and by the regen drift comparator that shares it) and by the `--backfill` branch/body match, so it can no longer flip an undelivered `todo` or `in-progress` row to `implemented`. A PR whose changed files cannot be read leaves its brief `unknown` and makes `--apply` refuse rather than guess. This is the same rule `deskdispatch` already applies to its delivered-already check, now pinned between the two implementations by one shared test vector.
