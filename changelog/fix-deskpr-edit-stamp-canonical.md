### Fixed
- `deskdispatch --stamp-only` no longer flips a PR's model stamp between a family alias and the full model id on every run. A request for `opus` over a standing `claude-opus-5-5` stamp under accepted authority now keeps the full id and writes nothing, and the full id over a standing alias still replaces it. The settlement applies only to an unattested stamp-only run, matches only the family word of the standing id, and is reported in the receipt. A run bound to a worker attestation, and the shared stamp writer, write exactly the selected model.
