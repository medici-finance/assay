### Fixed

- `cellctl up` no longer points every stale role at `up --plan`. `--plan` clears only a dead record (the checkpoint's supervisor has exited), so the stale row now names the verb that accepts the role's own class: `up --plan` for dead; `cellctl cadence <cell> recover <role> --confirm-stopped`, then `up --role <role>`, for alive and could-not-check records (including "no owner record survived"), listing any role-marked pids still running; and, once the prior harness has stopped, a hand repair when the lease could not be probed, since both verbs take the lease. `--plan`'s could-not-check refusal prints the same per-role line, and the comms preflight refusal and `--plan` comms line name `cellctl comms <cell> recover --confirm-stopped` for non-dead comms state, listing any comms-marked pids still running. Exit codes and recovery behaviour are unchanged.
