### Fixed
- `deskmonitor inbound` and `inbound-monitor.sh` no longer report a repo with more than 500 open issues as `MONITOR-DEGRADED` on every cycle. The read now walks the whole open set up to a ceiling of 10000 (the forge client's own open-issue page ceiling), and asks for one row past it: a read is truncated only when it holds MORE than `INBOUND_MONITOR_LIMIT`, so a set of exactly the ceiling is the whole set. The truncation message now reads "returned more than --limit N".
