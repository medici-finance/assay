- Migrate `deskwt` to Cobra and declared bindings through the shared desk CLI adapter. Root and per-verb help (including `maintain objects`) print to stdout and run before configuration, activation checks, locks or Git. Usage errors (unknown verbs or flags, bad values, wrong positional counts) now exit 2 before the kill switch and leave no audit row; domain refusals, prune and maintenance opt-ins, duration bounds and lock behaviour are unchanged. An explicit `--trace=false` turns off an inherited `DESK_TRACE`. See `docs/deskwt-cli-compat.md`.
