### Fixed
- The desk base, the five desk images, the harness and the desk-tools image no longer take the mode of a file they install from the checkout. Every build-context `COPY` onto `PATH` or into a shared directory now names `--chmod`, so a checkout made under umask 002 can no longer ship group-writable binaries, entrypoints or plugin hooks. The base, harness and desk-tools images also end in a build-time gate that fails the build if any installed file is writable by its group or others, and a static test fails on any new build-context install that lacks a root-only-writable `--chmod` (#6788).
