### Fixed
- The desk base, the five desk images, the harness and the desk-tools image no longer take the mode of a file they install from the checkout. Every build-context `COPY` onto `PATH` or into a shared directory now names `--chmod`, so a checkout made under umask 002 can no longer ship group-writable binaries, entrypoints or plugin hooks. The base, harness and desk-tools images also end in a build-time gate that first checks each root it scans exists, then fails the build if any installed path is set-id, is not root:root, is writable by its group or others, or is a symlink (under the base image's `/usr/local`, a symlink that dangles or resolves outside it). A static test fails on any new build-context install, direct or through a build stage, that lacks a root-only-writable `--chmod` without a set-id bit (#6788).
