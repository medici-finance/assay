### Fixed
- `writeguard` no longer refuses ordinary `gh` commands that mention `status` (`gh run view --json status,conclusion`, `gh pr checks | grep status`, `git status && gh pr view`). That pair is now cleared when every command in the text is a listed read spelled literally (`git status`, `gh pr view`, `list` or `checks`, `gh run view` or `list`, `gh issue view` or `list`, piped to `grep`, `head`, `tail` or `wc`). Their flags come from a closed list, and only literal field paths clear. A computed word, a `gh` alias, any other program and every `gh auth` form stay refused.
