### Changed
- `cellctl desk <house-cell> verify-desk` no longer hands the verify window the shared stream-root checkouts. It fetches `main` into each `CELL_ROOTS` checkout, cuts one detached, locked worktree per root at that commit under `<cell>/worktrees/verify-desk-roots/`, and exports `DESK_ROOTS` pointing at those trees with the same names. Before every cadence pass the trees are moved to the freshly fetched `origin/main`; a tree that cannot be makes the pass could-not-check, and a tree carrying local work is refused by name. The shared checkouts are never moved. `CELL_VERIFY_SHARED_ROOTS=1` restores the shared checkouts (#6814).
