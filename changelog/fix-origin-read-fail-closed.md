### Fixed
- When no repository is given, the desk-tools work-source reader now refuses (exit 6) to derive the repository from `origin` when config it does not merge could change origin's fetch URL as git resolves it: an `include`/`includeIf` directive in the repository config, or, with `extensions.worktreeConfig` enabled, a worktree-scope `include`/`includeIf`, `remote.origin.url` or `url.<base>.insteadOf` entry. The refusal names the kind of declaration and never a configured value. Worktree-scope `pushurl`, identity and credential keys, and an explicitly given repository, are unaffected. A guard test now fails if non-test desk-tools code adds a new repository-local remote URL read outside the existing, listed callers.
