### Fixed
- `cellctl` scratch sweeps now reclaim more of an abandoned task's build output and hold up better under failure. Every `work/<tool>-bin-<suffix>` entry counts as build output, so `deskpins-bin-4` and the like are covered, not only `cellctl-bin-<digits>`. Git data is now judged per entry, so build output beside a Git worktree can go while the worktree stays. An entry that cannot be read keeps its task and marks the sweep partial. The sweep now pins the identity of every task directory, `work` directory and planned entry before it measures them, and each removal walks to its target through open directory handles that must be those pinned directories. A directory swapped for a link, or a different directory or file renamed onto a planned path, after the sweep checked it therefore keeps the task or fails the removal instead of deleting another task's files. A failed or partial periodic sweep is recorded for every desk on the cell, so siblings make one retry instead of each sweeping in turn. No supervisor sweeps again until ten minutes after the first failure, doubling after each further one, never longer than the sweep interval, and the delay can no longer overflow for a very long interval or failure count.
