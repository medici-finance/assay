### Fixed
- `cellctl` scratch sweeps now reclaim more of an abandoned task's build output and hold up better under failure. Every `work/<tool>-bin-<suffix>` entry counts as build output, so `deskpins-bin-4` and the like are covered, not only `cellctl-bin-<digits>`. Git data is now judged per entry, so build output beside a Git worktree can go while the worktree stays. An entry that cannot be read keeps its task and marks the sweep partial. Each removal now walks to its target through open directory handles, so a directory swapped for a link after the sweep checked it fails the removal instead of redirecting it into another task. A failed or partial periodic sweep is recorded for every desk on the cell, so siblings make one retry instead of each sweeping in turn. That retry waits ten minutes after the first failure and doubles after each further one, up to the sweep interval. (#5353)
