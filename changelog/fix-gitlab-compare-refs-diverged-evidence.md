### Fixed
- `deskevidence` on GitLab no longer refuses every Evidence-branch landing whose landing home's HEAD differs from the branch tip (#6610). GitLab still serves no `CompareRefs`; instead the decision-gate board read asks GitLab one narrow question it answers exactly: is the home's HEAD the merge base of the two commits (so it is an ancestor of the tip), and which files differ between them. The landing proceeds only when the tip descends from the home's HEAD and every differing file is an Evidence path that was added or modified (this landing's target, a brief file, or a `docs/streams/verify-outcomes/` record). A changed brief is still read at the tip and applied to the judged board. Diverged or unrelated history, a compare GitLab reports as timed out, a listing at the file cap, a removal or rename, an unclean path and any non-Evidence change all stay could-not-check (exit 6). GitHub and other backends are unchanged.
