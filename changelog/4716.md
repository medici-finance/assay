### Added
- Every umbrella release publishes `sbom.spdx.json`, an SPDX 2.3 software bill of materials listing every Go module and the Go toolchain linked into each statusgen and qualgen binary and each desk-tools tarball, with a `pkg:golang` purl per module and each asset's sha256. The SBOM is in `checksums.txt` and attested like every other release asset.
