### Changed
- The public-repo write gate (`PublicRepoGate`, run by `deskpr`, `deskpost`, `deskreply`, `deskevidence` and `deskrelease cut`) now ranks exposure private < internal < public instead of requiring the allowed-repos token to equal the live visibility. An explicit, non-private entry authorizes a live read when its token is at least as exposed as the live value, so a `:public` entry now also authorizes a live-internal project. A live-public repo still passes only on `:public`; `:internal` on a live-public repo, `:private`, a missing token, an `owner/*` pattern-only match and an absent entry still refuse (exit 5), and a failed or unrecognised live read is still exit 6. Each refusal now names its cause. The "may predate the `:internal` token" sentence is gone from the refusal.
