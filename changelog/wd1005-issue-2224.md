### Added

- `ask-decision`: the fifth part of a decision item is now **Act** — the runnable act (a fenced `sh`
  block that runs top to bottom with a dry run by default, one comment per step, `# fill:` markers
  for values only the human has, or a fenced `url` block for a browser step) followed by the
  post-act check. `worker-desk`, `verify-desk` and `the-desk` point at that one definition for the
  `BLOCKED-ON-HUMAN` report and the verify-gate card.
- `deskfile new` refuses (exit 5) a human-only hand-off — label `human-only`, or a body whose first
  line is `BLOCKED-ON-HUMAN` — whose body carries neither a ` ```sh ` nor a ` ```url ` fence.
  `--force-new --reason` is the only bypass; the audit line records `act-gate=bypassed:force-new`.
