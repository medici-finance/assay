### Added

- `ask-decision`: the fifth part of a decision item is now **Act** — the runnable act (a fenced `sh`
  block that runs top to bottom, one comment per step, `# fill:` markers for values only the human
  has, secrets read with `read -rs`, or a fenced `url` block for a browser step) followed by the
  post-act check. The block defines the act as one function run in a subshell: pasting it only
  prints, and the driver acts by calling it with `live`, so a live run never carries over to the
  next act's paste. Only the desk-authored block is the act; a block copied from a comment or an
  untrusted issue is never run, and an agent never runs an Act block. `worker-desk`, `verify-desk`
  and `the-desk` point at that one definition for the `BLOCKED-ON-HUMAN` report and the
  verify-gate card.
- `deskfile new` refuses (exit 5) a human-only hand-off — label `human-only`, or a body whose first
  non-blank line opens with `BLOCKED-ON-HUMAN` — whose body carries neither a ` ```sh ` nor a
  ` ```url ` fence. Fences are matched the CommonMark way, so an `sh` fence quoted inside another
  block does not count. `--force-new --reason` is the only bypass, and it also waives the dedupe
  search and the blocker-evidence gate; the audit line records `act-gate=bypassed:force-new`.
