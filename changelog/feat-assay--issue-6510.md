### Changed
- The `HEARTBEAT` dead-man lease is now renewed by a progressing cell: when a desk verb completes an outward act the forge confirmed (a branch push, a PR create or edit, a review, comment or ready flip, an issue file or attach, an Evidence landing), the desk tools touch a still-fresh lease in the same call that writes the act's audit row, and the row ends `| heartbeat=renewed`. Reads, mints, ticks, dry runs, a push that moved no ref (logged `noop`, including `deskgit push` and `deskpr update` of a head the remote already holds) and failed acts never renew. A stale lease is never revived by a desk and still refuses every verb, and an absent file is never created, so only a lapsed lease needs a human touch (#6510).
