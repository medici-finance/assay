### Added
- `statusgen --lint` gains an advisory Verify-row rule, `grep-pipe-zero-count` (#1862). It flags a row whose final pipeline has a `grep` (`grep`, `egrep`, `fgrep`, `ggrep` or `git grep`) feeding a later stage under a zero-count Expect (`0`, ``prints `0` ``, ``output is `0` ``): under `verifyrun`'s `pipefail` that row fails when nothing matches and is decided by exit status alone when something does. A leading `!`, the guarded `{ grep … || [ $? -eq 1 ]; } |` form, a `≥ 1` Expect and an Expect that also declares a non-zero exit stay silent. The rule ships with a red/green fixture, an enforcement-status registry entry, the regenerated author-brief enforcement block and a rule note in the brief-rules reference. The current tree has no remaining hits.
