### Added
- `muhar -select` (opt-in): coverage-guided test selection. After the baseline, muhar records one coverage profile per top-level test and runs each mutant against only the tests that execute the function it mutates, plus an optional `select.always` list in the spec for tests that catch a mutant without executing it (source-text reads, golden files). Selection only removes tests, so it can turn caught into NOT CAUGHT but never a survivor green; the positive control runs under selection too, and a test that fails when run alone breaks the run. Baseline, exit codes, the `Totals:` line and `-shard`/`-j` are unchanged.
