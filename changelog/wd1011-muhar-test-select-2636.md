### Added
- `muhar -select` (opt-in): coverage-guided test selection. After the baseline, muhar records one coverage profile per top-level test and runs each mutant against only the tests that execute the function it mutates, plus an optional `select.always` list in the spec for tests that catch a mutant without executing it (source-text reads, golden files). Selection only removes tests, so it can turn caught into NOT CAUGHT but never a survivor green; the positive control runs under selection too, a test that fails when run alone breaks the run, and a mutation that cannot be attributed to one function body (a non-Go or uninstrumented file, a signature or package-level edit, an added or removed declaration) runs the full command. On the CI specs it gave identical reports and cut wall time by 31% on the deskkit spec and 54% on the deskmerge spec in a local run (small specs: no change); CI is not switched over here. Baseline, exit codes, the `Totals:` line and `-shard`/`-j` are unchanged.
