### Fixed
- statusgen's HELD/could-not-check scan (the verify-gate card, the model autoflip and `--close-verify`) no longer refuses a clean pass on text that is not a live row disposition. It now reads only the result cells of Evidence table rows, never their Command or Expect cells, and skips prose that only says what an exit code means ("could-not-check → exit 6") on a line that names no row. A row held in an earlier `### ` Evidence entry is no longer read once the last entry re-runs that same row, with a result, in a results table of its own and closes on its own strict `**VERIFY: PASS**`; a later entry that re-ran nothing or other rows replaces nothing, and an earlier hold in prose keeps every entry read. Headings, the marker and the re-run table count only where they render live. A genuine held row in the current entry still refuses, and anything the scan cannot classify is read as before (#1894).
