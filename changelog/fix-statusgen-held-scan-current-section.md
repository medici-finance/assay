### Fixed
- statusgen's HELD/could-not-check scan (the verify-gate card, the model autoflip and `--close-verify`) no longer refuses a clean pass on text that is not a live row disposition. It now reads only the result cells of Evidence table rows, never their Command or Expect cells, and skips prose that only says what an exit code means ("could-not-check → exit 6"). When a later `### ` Evidence entry records its own strict `**VERIFY: PASS**`, the earlier entries are no longer read. A genuine held row in the current entry still refuses, and anything the scan cannot classify is read as before (#1894).
