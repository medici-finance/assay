### Fixed
- `deskevidence` can now land Evidence for a verifier run admitted under an older desk-tools release, including `--remove-superseded` and outcome records. Before this, any tool change refused the landing. The landing accepts the change only when the running binary is a stamped release, it is strictly newer by semver than the admitted one, and it equals the desk-tools pin on the tracking repo's current `main`, read through the forge. If `main` cannot be read the result is could-not-check and the landing refuses. An accepted upgrade is recorded as a `Tool-Upgrade:` line in the landed commit, the draft-change body and the audit line. Row-execution admission still requires the admitted release exactly, and a change to any other input still refuses.
