### Fixed
- Desk-tools errors for a git remote that does not parse to `owner/repo` no longer echo URL userinfo. The shared remote parser now names the remote with every `user[:password]@` span replaced by `<redacted>@`, for https and ssh URLs, scp-like and bare forms, and the scp segment a rewritten remote can carry in its path. The scheme, host, port and path stay in the message. The `deskwt`, `deskpr` and `deskreply` origin checks now surface the parser's redacted message instead of repeating the raw origin URL, and `deskgit`'s own remote gate redacts the same way. A remote with no userinfo produces the same error text as before.
