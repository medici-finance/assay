### Fixed
- Test binaries that use the shared `gitquiet` harness now refuse to run when `TMPDIR` or `GOTMPDIR` is inside a git repository. Before, a fixture that ran git in an empty temporary directory could discover the enclosing repository and rewrite its config: from a linked worktree, the shared checkout's `remote.origin.url`. `TestVerifierGitRedacts` no longer depends on what encloses the temporary root. The probe keeps git's ownership check, and only an error that starts with git's own "not a git repository" reads as clean; any other failure, a root inside another account's repository included, is refused as could-not-check.
- The daily Gremlins sweep (`tools/gremlins/run.sh`) now sweeps a copy of the checkout without `.git` and never writes the checkout, so the `gitquiet` refusal does not put the desk packages at `probe-red`.
