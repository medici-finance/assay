### Fixed
- `cellctl` desks now sweep managed task scratch themselves while their supervisor runs. Before, nothing scheduled the sweep, so a long-running cell's scratch grew until an operator ran `cellctl scratch <cell> sweep --apply` by hand. The first sweep runs ten minutes after launch and later ones every `CELL_SCRATCH_SWEEP_INTERVAL` (default `6h`, `0` turns it off). Sibling desks share one sweep per interval, and the launch path still never walks history. Sweeps also reclaim one new kind of data: the `work/go-build<digits>` and `work/cellctl-bin-<digits>` output of tasks whose session died without acknowledging them. This happens only when the task's lease is free, its child group is reaped, it is older than the retention max-age and it holds no Git data. The task's record, diagnostics and other work stay, and a `work` directory that is a link is never followed. (#5353)
