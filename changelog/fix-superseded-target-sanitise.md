### Fixed
- `deskclose` reads an item reference only when the whole value is one (`N`, `#N`, `!N`, `owner/repo#N`, or the object's web URL): a `Superseded-By` proposal value or disposition `Evidence` with anything ahead of the reference is no longer accepted on its trailing number. A web URL's host must be a plain host name (optional port) and each project-path segment plain `[A-Za-z0-9_.-]`; a number with a leading zero is refused. Receipts, dry-run lines, audit details, refusals and comments now print a reference re-rendered from its parse in canonical `owner/repo#N` form (or a fixed placeholder), never the text it was read from; a disposition record's Verdict, RecordedAt and RecordedBy print only when they are one plain word. Evidence that stands in for a missing target is used only through its parse.
