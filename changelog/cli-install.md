### Changed
- `deskinstall` now parses its flags with Cobra through the desk CLI adapter. `--help`, `-h` and `help` print the generated help to stdout and exit 0 before any file, network or harness read. Running it with no arguments still prints help to stderr and exits 5. Every legacy flag keeps its spelling, `--version`, `-version` and a sole `version` still print the version, and unknown words, `--` and stray arguments are still refused with exit 5 as `unknown argument "<word>"`. Mode rules, refusals and exit codes 0, 1, 2 and 5 are unchanged. The sha256 and build-attestation checks stay inside the installer, and no flag skips them. deskinstall reads no environment variable or config key. Additive forms: `--flag=value`, explicit boolean values (`--check=false`), and the shared `--perf-*` attribution flags. Refusals no longer reprint the usage screen. Parse errors end with `Run 'deskinstall --help' for usage.`, and a missing value now reads `flag needs an argument: --<flag>`.
