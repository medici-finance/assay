### Fixed
- statusgen: a merged PR's `Brief: <stream>/<NN>` trailer in any configured root (`DESK_ROOTS`, `--sibling-root`) is now the delivery witness for a brief whose file lives in a different root. Next-up holds the row as already merged and names the PR as `owner/repo#N`, and reconcile writes the row with that PR as its witness. A configured root that cannot be read is reported as could-not-check and holds or writes nothing, and it counts as a possible carrier of a stream, so a trailer for a stream it might share is credited to no board. Only roots the board's own `docs/streams/graph-repos.yaml` publishes are read, and no unpublished root's repo name or checkout path reaches STATUS.md, a notice or reconcile's witness. The other root is read at its integration branch (not the checkout's HEAD), a merge carrying more than one `Brief:` trailer is no witness, and a trailer for a stream name another configured root also carries is credited to no board.
