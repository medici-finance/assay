### Fixed
- The verifier's instrument pin check now hashes the binary a cellctl shim runs instead of the shim script itself, so a host whose pinned tools sit behind cellctl shims no longer reads as pin drift. A shim is followed only when it is byte-for-byte the shim cellctl generates (the generator and the check now share one template); a shim that runs a different build fails as drift naming that binary, and any hand-edited shim, hotfix shim, or shim whose binary is missing or not a plain absolute path reports could-not-check rather than passing.
