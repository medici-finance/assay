### Fixed

- `deskdispatch` no longer refuses every human-gated dispatch (exit 6 at `decision-gate`) in a repo that carries no `tools/decision-issue.sh`, which no install path supplies (#6131). desk-tools now ships `deskdecision`, a pure-Go port of the helper's `ensure` verb, and the gate resolves the way the claim tool does: `deskdecision` on `PATH`, then the script under the resolved root (`--claim-root` when given, else `--root`), then a refusal naming both. The port keeps the script's argv, exit codes (0 / 5 / 6) and issue body, and dedupes on the same `<!-- decision-gate: <id> -->` marker, the legacy `<!-- needs-decision: <id> -->` marker and the brief's `decision-issue: <N>` frontmatter, so a repo that moves between the script and the port never files a second issue. It writes through the deskkit forge client (GitHub or GitLab) as the role `deskdispatch` names with `--as`, under that role's own credential, never an ambient login.
