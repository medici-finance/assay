### Fixed
- `deskwt add` now rolls back the worktree directory when `git worktree add` fails after creating it (for example a failing `post-checkout` hook), so re-running the same dispatch key no longer dies on "target already exists".
- `deskdispatch` names the exact `deskwt remove <path>` command when a re-dispatch meets a stale target directory, and when a run aborts after creating its worktree.
- Rollback requires an exclusive directory reservation, unchanged directory identity, and the existing sanctioned-path check; Git stderr never grants cleanup ownership. All add-step failures share this check.
- Reclaim hints quote spaced parent paths and distinguish retrying a directory name from fresh review homes.
