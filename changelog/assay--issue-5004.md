- Fix GitLab board pushes still running an older embedded board-push script after a statusgen upgrade, which made fixes like the http extraheader reset never reach the pipeline (#5004). The new `statusgen migrate gitlab-anchors --root .` refreshes the `.statusgen-pushcred` and `.statusgen-boardadd` anchors in `.gitlab-ci.yml` in place and leaves the rest of the file alone. Migration 0005 runs it during the upgrade. `statusgen --lint` now prints a NOTICE with that command when an embedded anchor differs from the running statusgen's copy, and a re-run of `statusgen init` marks the anchor `STALE`.
- Fix the GitLab board push going out as the CI job token when the runner's checkout carries a `url.*.insteadOf` rewrite that puts the token in the URL. The token-variable push and its dry-run preflight now pin the push URL back to itself without the userinfo. A remote name whose push URL carries userinfo gets a NOTICE (#5004).
