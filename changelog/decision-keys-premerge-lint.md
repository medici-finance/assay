### Added
- `statusgen --lint` now judges a pull request that delivers a `gate: human` brief before it merges. On a `pull_request` event it reads the pull request's body; each brief named in a `Brief:` trailer counts as moved to `implemented`, which is what reconcile does on merge. The decision-gate hold (lifecycle-v1 §4.5) then refuses the PR if that brief has no `decision-issue:` and `ruling:`. The design-approval gate (§4.4) refuses it if a post-cutover risk-gated brief has no `design:`. Previously those keys were found missing only after the merge, when reconcile's lint hold held the row. Partial deliveries, briefs already at `implemented` or later, and runs outside a pull request event are unchanged. An unreadable event payload fails closed.
