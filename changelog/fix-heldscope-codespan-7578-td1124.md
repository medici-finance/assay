### Fixed
- `statusgen verifyflip` no longer refuses a clean latest run because an earlier entry quotes a placeholder such as `<a verb ...>`. The check for an element left open before the latest run's heading now skips such text inside a certain inline code span, and the formatting tags inside a cell of the witness table `verifyrun` writes, since neither can carry past its span or cell on the page. A cell holds its formatting tags only while it opens no element that pushes its own formatting marker (`object`, `applet`, `marquee`, or a table-structure or `template` tag), so a witness row holding any of them is not exempt. The exemption also ends at the first line after the table's delimiter row that is not a witness row, such as a line holding only `|`, because the page may end the table there and render the rows after it as text. The same text in prose, or in a span or table the check cannot settle, still counts, so the check still refuses when the page might hide the heading.
