### Added
- A composite GitHub Action for muhar, `actions/muhar` (#2642), used as `uses: medici-finance/assay/actions/muhar@<full-commit-sha>`. It builds muhar from source at the pinned commit, runs one or more mutation specs (with `jobs`, `shard`, `working-directory` and optional Go setup through a SHA-pinned `actions/setup-go`), writes every per-mutant verdict and the `Totals:` line to the job summary, and sets `caught`, `not-caught`, `could-not-mutate` and `result` outputs. Exit 2 (harness broken) always fails the step as "harness broken — not clean"; NOT CAUGHT and could-not-mutate fail by default and can each be turned into a warning. A `muhar-version` input is reserved for a future release-binary install and refuses any value until then. The action's logic lives in `muhar-action.sh` with an offline fixture suite that runs inside `tools/desk`'s `go test`, alongside tests that hold the action's parser to the report text muhar really prints.
