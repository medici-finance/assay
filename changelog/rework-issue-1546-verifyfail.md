### Fixed
- The desk-tools release-stamp guard (`TestVersionStampedFromReleaseWorkflow`) now reads `.github/workflows/release.yml`, where the desk-tools build step actually stamps `deskkit.ReleaseTag`. It used to read a `release-desk.yml` this repository never had, so it skipped on every run and could never fail. It now checks the build step itself (a stamp that survives only in a comment, or is fed the commit instead of the release tag, fails it), and a new mutation control proves it goes red on each way the stamp can break.
- Guard tests in `tools/desk/internal/deskkit` can no longer skip unnoticed on a full checkout. When the tree carries `.github/workflows/`, a missing fixture fails the test unless the test is on a committed register of known-absent fixtures, listed with the exact path.
