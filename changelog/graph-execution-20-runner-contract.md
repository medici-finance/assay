### Added
- The shared loop-admin runner protocol (`spec/loop-admin-runner-v1.md`, `schemas/loop-admin-runner-v1.json`) and the independent `loopadmin` Go module that implements it (`loopadmin/runner`): start, observe, cancel and reconcile under a stable launch identity, strict standing-desk and workflow-stage modes, capability declarations with mandatory-field refusal, a generation fence on result acceptance, credential exclusion that decodes and walks extension values (nested keys, escaped tokens, Basic credentials), strict decoding (exact-case keys, no repeated key, no null for a defined field, nothing after the request), terminal states that absorb any later report, a result that must echo its invocation identity and a reported model, and refusals that never echo request or result content. Unknown outcomes, missing usage and unconfirmed cancels stay unknown. It ships an in-memory fake adapter, an offline conformance kit, a fixture that bypasses the contract's fence to show the caller's own claim-generation check still refuses a fenced result, and a mutation gate. No provider client or provider call. The module's CI job is staged at `ci/staged-workflows/loopadmin.yml` pending maintainer promotion.
