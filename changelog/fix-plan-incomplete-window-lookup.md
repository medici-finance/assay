- fanoutloop: `plan` reads the delivering PRs as a bounded window of the most recent open and merged changes. When that window is incomplete, each queued brief the window does not cover is now looked up by its `Brief:` trailer through the forge's search. A merged hit lists the row under LANDED-UNRECONCILED instead of offering it as IMPLEMENT. A failed or partial lookup, or a forge backend without the search, lists it under a new COULD-NOT-CHECK heading and does not dispatch it. A complete window makes no lookup.
- fanoutloop: a LANDED-UNRECONCILED row whose brief statusgen's lint would hold now names the missing `design:`, `decision-issue:` or `ruling:` key, which is human work, instead of suggesting `statusgen reconcile --backfill --apply`.
- fanoutloop: the per-brief lookups past an incomplete window run in queue priority order (rework rows, then Next-up rows in board order), and the first rate-limit answer ends them: every brief not yet looked up is listed under COULD-NOT-CHECK without another search. A lookup that finds several PRs prefers the newest, and the plan header now states the COULD-NOT-CHECK count.
