### Fixed
- `deskpr update` and `deskpr edit` no longer resolve the PR from the worktree's branch name alone. `deskpr update --pr N` (or `--branch B`) pushes HEAD to the head branch the forge reports for that PR, so a worktree on a differently named branch, or a detached HEAD, can push a follow-up when another worktree holds the PR's branch; HEAD must descend from the PR's current head commit. `deskpr edit --pr N` now runs from any worktree, including one with no commits ahead of the default branch, because it pushes nothing.
