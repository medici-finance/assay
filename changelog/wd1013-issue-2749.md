### Fixed
- `deskdispatch --prompt-file F` no longer overwrites the caller's own file with the ~40 KB assembled assignment. The prompt is written to a new sibling `<F without extension>.emitted.md` (next to the `.packet.md`) and that path is printed on stdout; `F` itself is never modified, and a directory given as `F` is refused before the claim.
- The emitted prompt replaces its destination atomically with mode `0600`, without following a pre-existing link or retaining a wider file mode.
### Changed
- Callers must check dispatch success and read the emitted path printed on stdout instead of reading `F` back. Use distinct file stems for concurrent dispatches and keep these generated siblings outside agent worktrees; a refused dispatch may leave an older emitted file in place.
