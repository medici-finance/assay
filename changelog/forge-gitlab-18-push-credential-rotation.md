- Add `deskfleet push-token rotate` and `deskfleet push-token check` (#2910). `rotate` replaces the GitLab board-push credential `STATUSGEN_PUSH_TOKEN` in one process: it rotates the project access token, writes the new value into the masked, protected CI/CD variable with every flag sent explicitly, reads the variable back, and proves the new token by its record, its own self-introspection and a receive-pack probe on the API host. The value is never printed, logged, or put in argv, the environment or a file. A read-back that disagrees, or cannot be read, revokes the new token and confirms the revoke. `check` is a read-only monitor under a separate reader credential that alarms below `--min-days` (default 7). See docs/adopting-assay-gitlab.md §2c "Rotating it".
