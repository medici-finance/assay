### Fixed

- The ready-flip checks-green gate no longer passes a head whose ruleset-required checks never reported. On GitHub the legacy required-status-checks endpoint shows only classic branch protection: on a branch whose required checks come from a ruleset it answers 404, and that 404 used to be read as "nothing required", so a head with one green check passed. The required set is now the union of the classic contexts and the contexts the branch's rulesets require, on every path (legacy 200, legacy 404, and the 403 path read without administration rights). If the rulesets cannot be read, the set is could-not-check, never a partial list that looks complete.
