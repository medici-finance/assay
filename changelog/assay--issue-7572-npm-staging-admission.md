### Added
- `deskdispatch --stage-npm` is an admitted npm staging step for a verifier run: it runs `npm ci --offline --ignore-scripts` from a cache filled before the run against the home's attested `package-lock.json` (and, with `--build`, the package's own build script), then binds a digest of the staged `node_modules/` (and `dist/`) to the run record once. Pre-work admission passes over only those staged directories, and only while they still hash to that digest; with no staging record admission is unchanged. `statusgen verifyrun` writes the digest on the witness as an `Npm-Staging: sha256:<hex>` line, the npm counterpart of `Module-Cache:`.
