### Fixed
- `statusgen verifyrun`: an admitted row can no longer reach the invoking user's stored forge login or mint a role credential. Before a row's shell starts, the run now removes `HOME`, `XDG_CONFIG_HOME`, `DESK_LOOP`, `CELLCTL_GH_AMBIENT` and every `GH_*` and `ASSAY_*` variable, whatever their case. It also drops a `GIT_CONFIG_GLOBAL` that points anywhere except the null device. Each run gives its rows a fresh, empty `HOME` under its own scratch directory and removes it when the run ends. `statusgen rowread` inside an admitted row now forwards its request over a socket in that scratch directory. The run answers it in its own process, holding the read role the row no longer has. The rowread verb's closed read set still applies, and an unreachable run gives could-not-check. Verify rows that called `gh`, `desktoken` or an `ASSAY_*` setting directly from the admitted environment now get no credential. Such rows must use `statusgen rowread` or run outside admission.
