# Deck typography

Set a coherent scale before fitting individual slides. On a 1280 × 720 stage, start with a 52 px display, 30 px section head, 18 px subhead, 15–16 px body and 12 px minimum caption. Test with the actual font and viewing distance. Projected slides usually need larger type than a read-ahead deck.

Cap running paragraphs near 60 characters per line. Leave tables and figures the full measure. Start paragraphs and lists at 1.5 leading and table cells at 1.45. Balance multiline headlines, align comparable numeric values with tabular figures, and use uppercase tracking sparingly. Use the project's licensed local fonts and inspect fallbacks after export.

When content overflows, cut it, group it or split the slide before shrinking the type. Compare the densest slide at viewing size with its neighbours. Inspect both the screenshot and the exported page for clipping or a substituted font. The sibling deck-author skill carries the structural checker and the render-check commands.
