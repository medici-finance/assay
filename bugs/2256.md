# Issue 2256 — overwritten image-layer secrets remain detectable

Resolution claim: the scanner repair already landed in PR #2264 (merge
`3e76dacadb43de0d44bb5aeb522a98b3725b14db`). Each manifest-listed layer is
extracted and scanned separately. A later same-path write, sandwich of writes,
directory replacement or whiteout cannot hide a secret that remains in an
earlier distributable layer. This carrier changes no scanner implementation.

The existing regressions cover six overwrite variants, three sandwich variants
and directory replacement. They require exit 1 and the original secret path;
an unrelated scan error does not count as detection. The canonical merged-layer
mutant must break all ten overwrite/sandwich/directory assertions while the
remaining assertions continue passing.

unrelated assertion. Fixtures use local scratch images and synthetic material;
the suite pulls no image. The tested revision was
`ecb8c74a4ae8462e4f9388e43dfbbb745d8b36be`; the scanner, fixture suite, label
