# Issue 4172 — cadence cache maintenance scope reconciliation

Resolution claim: the existing cadence supervisor triggers the existing cache
maintenance owner after completed child finalization and again at the next due
boundary. Dirty accounting and a report aging during the interval therefore
recover before the next managed enrollment without manual clean. First startup
and interactive mode retain bounded refusal and operator maintenance.

The coordinator's recorded scope is outcome (a), not a new driver fork:
https://github.com/medici-finance/assay/issues/4172#issuecomment-6354063056

The supervisor retains its existing role lease and heartbeat while maintenance
finishes. Cache inventory still releases admission custody and uses the existing
root, policy, active-consumer, free-space and enrollment revalidation. Refresh
waits the existing filesystem timestamp margin before measuring; no report is
made fresh by changing its timestamp alone. Maintenance failure is recorded in
the existing checkpoint and preserves fail-closed next enrollment. Uncertain
children never authorize maintenance. No daemon, additional scheduler, launch
serializer or recursive startup/Finish is added.

Evidence: TestCadenceCacheMaintenance executes actual managed children across
build/Finish/next-pass enrollment and an accounting-age crossing, without manual
Check between passes. It also refuses subsequent enrollment when ownership
evidence becomes corrupt. TestBetweenPassMaintenanceCustody and
TestUncertainPassDoesNotMaintain cover role custody, heartbeat, cancellation and
unreaped children. TestCacheMaintenanceCancellation and
TestCacheMaintenanceFresh cover canceled refresh and avoiding recursive fresh
accounting. The committed cadence-cache-mutations.json supplies fail-first
controls for the trigger, every-wake boundary, failure recording, timestamp
settling, fresh fast path and an independent public maintenance caller.

This carrier is an implementation resolution claim for independent review and
human merge, not an issue-close or verification verdict.
