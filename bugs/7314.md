# Standalone editorial plugin

Writing projects can install `editorial@assay` independently in Claude Code and Codex, or select `editorial` from a Cursor team marketplace. The self-contained package ships its own skills and references. Existing methodology-plugin invocations remain available.

The native harness-generator tests verify both marketplace entries, the complete package payload, and parity with the shared canonical article skills. Installation and first-use examples are in [the plugin guide](../plugins/editorial/README.md).
