# Issue 7308 — explicit approval for a plain-shell command replacement

A numbered acceptance transition can now carry a v2 human approval for the
whole command of an existing shell check. The approval names the row as
`PlainCommand` and binds its predecessor and amendment. Each revision must
supply the entire command the runner reads. Every other row cell must match.

`TestPlainCommandApproval` exercises a merged Git amendment and checks that
`verifyrun` executes the approved command and records its observed exit.
It also rejects mismatched approvals and changes to the other cells.
